# AMG_uncertainty

# The repository contains
- Scripts to perform the uncertainty propagation in the AMG model (Clivot et al. 2019), either using an analytical method or a Monte Carlo approach.
- Input data from QualiAgro exprimental site (Fujisaki et al., 2026; Levavasseur et al., 2021), yield from the French regional statistics Agreste (https://agreste.agriculture.gouv.fr/agreste-web/disaron/SAA-SeriesLongues/detail/).
